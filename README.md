# 👋 Bienvenido

Bienvenido a mi repositorio de **Whoami Labs**.

Este repositorio reúne la documentación de todas las máquinas virtuales que voy resolviendo dentro de la plataforma **Whoami Labs**, con el objetivo de fortalecer mis conocimientos en **Pentesting**, **Ciberseguridad Ofensiva** y **Escalada de Privilegios**.

Cada writeup refleja el proceso completo seguido durante la resolución de la máquina, desde el reconocimiento inicial hasta la obtención de privilegios elevados, documentando la metodología utilizada, las herramientas empleadas y las lecciones aprendidas.

---

# 🎯 Objetivos

Este repositorio tiene como finalidad:

* Documentar cada laboratorio de forma profesional.
* Mejorar mi metodología de Pentesting.
* Desarrollar habilidades de enumeración.
* Practicar técnicas de explotación.
* Aprender escalada de privilegios en Linux y Windows.
* Crear una base de conocimiento reutilizable.
* Registrar mi progreso dentro de Whoami Labs.
